# 🖼️ الكاروسيل — Carousels (Instagram / Facebook / LinkedIn)

## الهدف
محتوى تعليمي أو قيمة مضافة يخلي المتابع **يحفظ (Save)** و**يشارك (Share)** — وهذول أقوى إشارتين للخوارزمية.

## المواصفات والوقت ⏱️

| البند | القاعدة |
|---|---|
| عدد السلايدات | **٦ – ١٠ سلايدات** (المثالي ٧–٨) |
| سلايد الغلاف | **عنوان ٥ – ٨ كلمات بس** |
| كل سلايد داخلي | **١٥ – ٣٠ كلمة كحد أعلى** |
| وقت القراءة | ٣ – ٥ ثواني لكل سلايد ← المجموع **٣٠ – ٦٠ ثانية** |
| الكابشن | **٨٠ – ١٥٠ كلمة** — أول سطر لازم يشد (أول ١٢٥ حرف تبين قبل "المزيد") |
| الهاشتاگات | **٥ – ١٠** (مزيج: عام + عراقي + خاص بالمجال) |
| المقاس | 1080×1350 (4:5) |

## النبرة 🎙️
- **معلّم صديق** — نشرح بسهولة كأنك تشرح لأخوك.
- واضحة ومنظمة، فيها شوية هضامة.
- إيموجي معتدل (١–٢ بكل سلايد).

## الهيكل
1. **سلايد ١ — الغلاف (Hook):** وعد واضح أو فضول. ("٥ أغلاط تخرب بشرتك بالصيف ☀️")
2. **سلايد ٢ — ليش يهمك؟:** المشكلة أو السياق بسطرين.
3. **سلايد ٣ – ٨ — المحتوى:** نقطة وحدة بكل سلايد، رقم + عنوان قصير + شرح سطر أو سطرين.
4. **سلايد قبل الأخير — الخلاصة:** ملخص سريع أو "النصيحة الذهبية".
5. **السلايد الأخير — CTA:** "احفظ البوست 📌 ودزه لصاحبك" + اسم الحساب.

## قواعد التصميم (ملاحظات للمصمم)
- نفس الخط والألوان بكل السلايدات.
- سهم أو "اسحب ←" بأول سلايد.
- رقم السلايد (٢/٨) يساعد المتابع يكمل.

## أوقات النشر المقترحة (توقيت بغداد) 🕒
- **٧ – ١٠ بالليل** هو الأقوى للمحتوى التعليمي.
- أيام: **الأحد – الخميس**، والجمعة عصراً.
- التكرار: **٢ – ٣ كاروسيلات بالأسبوع**.

## مثال ✍️
**الموضوع:** صالون حلاقة رجالي — نصايح للحية.

- **سلايد ١:** "لحيتك ما تطلع حلوة؟ 🧔 هاي الأسباب"
- **سلايد ٢:** "مو دائماً المشكلة بالجينات… أغلبها عادات يومية نسويها غلط."
- **سلايد ٣:** "١. تغسلها بشامبو الراس ❌ — ينشفها. استخدم غسول خاص باللحية."
- **سلايد ٤:** "٢. ما تمشطها ❌ — المشط يرتب الشعر ويوزع الزيت الطبيعي."
- **سلايد ٥:** "٣. تحلگها بنفسك كل يومين ❌ — خليها تطول ٤ أسابيع گبل أول تحديد."
- **سلايد ٦:** "٤. ماكو زيت لحية ❌ — گطرتين باليوم تفرق هواية."
- **سلايد ٧:** "الخلاصة: غسول + زيت + مشط + صبر = لحية كشخة ✅"
- **سلايد ٨:** "احفظ البوست 📌 ودزه لصاحبك اللي لحيته تعبانة 😂"

## ممنوعات
- سلايد مليان كلام (أكثر من ٣٠ كلمة).
- غلاف عام وممل ("نصائح مفيدة").
- كاروسيل بدون CTA للحفظ أو المشاركة.
